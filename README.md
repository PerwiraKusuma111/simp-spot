# Spotify Mobile Mode (v1.1.0)

Ekstensi browser Android (**Microsoft Edge Canary**, **Quetta**, **Kiwi**, **Mises**) yang mengubah tampilan **Spotify Web Desktop** (`https://open.spotify.com`) menjadi tampilan **Spotify Mobile** lengkap dengan semua kontrol pemutar yang berfungsi penuh.

## Fitur
- **Header Beranda Ringkas** — judul **Spotify** tebal di kiri atas + tombol **Profil** (atau tombol **Masuk** jika belum login) di kanan atas, dengan padding pinggir yang lebih tipis dan lega.
- **Floating Mini-Player + Full-Screen Now Playing** — ketuk mini-player untuk membuka tampilan pemutar layar penuh (cover album HD, judul, artis, suka/like, dan swipe ke bawah untuk menutup).
- **Slider Progress Lagu Interaktif** — ketuk atau geser halus langsung di layar Now Playing untuk lompat ke menit/detik mana saja.
- **Kontrol Lengkap ala Aplikasi Spotify Mobile** — Acak (Shuffle), Sebelumnya, Putar/Jeda, Berikutnya, Ulangi (Repeat All & Repeat One), Volume slider, **Lirik**, dan **Antrean (Queue)**.
- **Navigasi Bawah 3 Tab** — **Beranda**, **Cari** (dengan saran otomatis asli Spotify), dan **Koleksi** (langsung terbuka dalam mode penuh/diperluas menampilkan semua playlist & Lagu yang Disukai).
- **Desktop UA Otomatis khusus Spotify** — Spotify Web langsung jalan penuh di HP tanpa harus menyalakan mode Situs Desktop untuk semua website lain.
- **Kunci Anti Pinch-Zoom & Skala Konten** — bisa diatur lewat popup ekstensi, plus tombol pindah cepat ke tampilan **Asli** kapan saja.
