# Spotify Mobile Mode (v1.6.2)

Ekstensi browser Android (**Microsoft Edge Canary**, **Quetta**, **Kiwi**, **Mises**) yang mengubah tampilan **Spotify Web Desktop** (`https://open.spotify.com`) menjadi tampilan **Spotify Mobile** lengkap dengan semua kontrol pemutar yang berfungsi penuh dan ringan.

## Fitur Utama
- **Header Beranda Lengkap & Ringkas** — judul **Spotify** di kiri atas, kolom **Cari lagu...** tepat di sampingnya, dan tombol **Profil** (atau **Masuk**) di kanan atas.
- **Pencarian Langsung di Beranda + Saran Pencarian** — klik kolom cari untuk memunculkan saran pencarian & riwayat asli Spotify langsung mengambang di atas Beranda tanpa pindah halaman. Tap luar atau `←` untuk menutup instan (0ms), tekan tombol cari hijau / Enter untuk membuka halaman hasil penuh.
- **Rak "Jelajahi semua" 2 Susun Horizontal di Beranda** — kategori genre warna-warni khas Spotify langsung tersedia di Beranda dan bisa digulir ke kanan/kiri.
- **Navigasi Bawah 2 Tab Instan (0ms)** — **Beranda** dan **Koleksi** (langsung terbuka dalam mode penuh menampilkan semua playlist & Lagu yang Disukai) tanpa lag perpindahan tab.
- **Floating Mini-Player + Full-Screen Now Playing** — ketuk mini-player untuk membuka pemutar layar penuh (cover album HD, slider progress interaktif tap & drag, Acak, Sebelumnya, Putar/Jeda, Berikutnya, Ulangi, Volume slider, 1-klik Like/Unlike, swipe ke bawah untuk menutup).
- **Menu Opsi Lagu (Titik 3 `⋮`)** — bottom sheet lengkap untuk Like/Unlike, Tambah ke Playlist, Bagikan Link Lagu, Lihat Artis, Lihat Album, Menu Opsi Spotify, dan pindah ke Tampilan Desktop Asli.
- **Lirik Layar Penuh Bersih** — bebas tombol kecil bawaan yang mengganggu, dilengkapi tombol `×` kanan atas dengan penutupan bersih tanpa animasi patah-patah.
- **Split View 50/50 (Info Lagu + Antrean)** — sisi kiri menampilkan Info Lagu live (dengan klik link artis/perluas dinonaktifkan agar tidak salah pencet), sisi kanan menampilkan daftar Antrean interaktif yang bisa di-scroll, disegarkan, dan diputar langsung.
- **Desktop UA Otomatis khusus Spotify** — Spotify Web langsung jalan penuh di HP tanpa harus mengaktifkan mode Situs Desktop untuk website lain.
- **Anti Pinch-Zoom & Pengaturan Skala** — bisa diatur kapan saja lewat popup ekstensi.

## Cara Pasang
1. **Microsoft Edge Canary Android:** unduh `spotify-mobile-ext.crx`, buka **Extensions** (mode Developer) -> **Install by .crx**, lalu pilih file yang diunduh.
2. **Quetta / Kiwi / Mises Browser:** unduh `spotify-mobile-ext.zip`, buka menu **Extensions** -> **+ (from .zip/.crx/.user.js)**, lalu pilih file ZIP.
3. Buka `https://open.spotify.com` dan muat ulang halaman.
